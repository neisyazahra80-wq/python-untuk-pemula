# Python untuk Pemula

Repositori dokumentasi praktikum pemrograman Python dasar menggunakan lingkungan Arch Linux (WSL). Setiap materi dilengkapi dengan kode sumber (`.py`) dan bukti tangkapan layar eksekusi program di folder `screenshots/`.

## Cara Menjalankan

Pastikan Python 3 sudah terpasang, lalu jalankan berkas yang diinginkan lewat terminal:

```bash
python nama_file.py
```
